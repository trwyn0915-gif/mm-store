# MM World — وضعیت نسخه آنلاین

این شاخه مستقل برای ساخت بازی نقش‌آفرینی آنلاین MM است. مخزن اصلی و پنل خدمات اتحادیه MM و اپلیکیشن کاربرگ مدرسه در این تغییرات دست‌نخورده می‌مانند.

## نسخه قابل توسعه

- رابط بازی در `online-test/index.html` قرار دارد.
- بازی دوبعدی از بالا به پایین با نقشه بزرگ، دهکده، بازارچه، خانه مسافر، دریاچه، جنگل، نگهبان دهکده و گیاهان قابل جمع‌آوری ساخته شده است.
- حرکت با WASD/کلیدهای جهت‌دار و دکمه‌های لمسی موبایل انجام می‌شود.
- برخورد پایه با درخت‌ها، ساختمان‌ها و دریاچه پیاده‌سازی شده است.
- بازیکنان با ورود ناشناس Supabase شناسه می‌گیرند؛ موقعیت و ظاهرشان از طریق Realtime Presence/Broadcast به دیگران نمایش داده می‌شود.
- چت جهانی در جدول `world_chat` ذخیره می‌شود.
- نام، ظاهر، موقعیت، سطح و تجربه شخصیت در `world_players` ذخیره می‌شود.
- ماموریت ابتدایی جمع‌آوری سه گیاه، تجربه و سکه محلی دارد.
- فایل manifest و service worker برای نصب‌پذیری اولیه اضافه شده‌اند.

## راه‌اندازی و انتشار

1. پروژه Supabase مورد استفاده این بازی باید فعال باشد.
2. Anonymous Sign-ins باید در Supabase Auth فعال باشد.
3. جداول و سیاست‌های RLS در `schema.sql` باید نصب شده باشند.
4. کلید publishable فقط در مرورگر استفاده می‌شود؛ هرگز کلید secret یا service_role را منتشر نکنید.
5. برای انتشار این نسخه، فایل‌های همین شاخه باید پس از بازبینی به مسیر انتشار GitHub Pages منتقل شوند.

**توجه:** گردش کار فعلی GitHub Pages فقط روی شاخه `main` اجرا می‌شود. بنابراین ثبت این نسخه در شاخه `online-world-foundation` به‌تنهایی آن را روی لینک عمومی منتشر نمی‌کند. فایل‌های main عمداً تغییر نکرده‌اند.

## محدودیت‌ها و کارهای باقی‌مانده

- ورود و نمایش هم‌زمان چند بازیکن باید در دو دستگاه/مرورگر واقعی آزمایش شود.
- برخورد بازیکنان با یکدیگر، سیستم گروه/دوستی، نقشه‌های جداگانه، اقتصاد امن، ذخیره سمت سرور موجودی و ماموریت‌ها، ضدتقلب و محدودسازی نرخ چت هنوز کامل نیست.
- سکه و وضعیت جمع‌آوری گیاه‌ها فعلاً در حافظه محلی مرورگر ذخیره می‌شوند؛ برای بازی پایدار چنددستگاهی باید به مدل داده سمت سرور منتقل شوند.
- این نسخه یک پایه قابل بازی برای توسعه است، نه MMORPG کامل و آماده انتشار.
