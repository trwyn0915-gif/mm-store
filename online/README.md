# RIP Online World — مرحله اول

این پوشه پایه فنی دنیای مشترک آنلاین بازی RIP است. نسخه داستانی فعلی دست‌نخورده می‌ماند؛ این پیاده‌سازی ابتدا در یک شاخه جدا ساخته می‌شود.

## معماری انتخاب‌شده

- بازی و فایل‌های نمایشی: GitHub Pages
- حساب بازیکن: ورود ناشناس Supabase Auth (هر بازیکن یک شناسه پایدار می‌گیرد)
- حضور و حرکت زنده: Supabase Realtime Presence و Broadcast
- شخصیت و پیشرفت ذخیره‌شده: جدول `world_players`
- چت ذخیره‌شده: جدول `world_chat`

GitHub Pages فقط فایل‌های سایت را میزبانی می‌کند و به‌تنهایی سرور چندنفره نیست. Supabase سرویس آنلاین جداگانه است.

## راه‌اندازی سرویس

1. یک پروژه Supabase بساز.
2. در Authentication، ورود Anonymous را فعال کن.
3. محتوای `schema.sql` را در SQL Editor اجرا کن.
4. از Project Settings بخش API، Project URL و anon/publishable key را بردار.
5. `config.example.js` را به `config.js` کپی کن و مقادیر واقعی را در آن قرار بده.
6. هرگز service_role یا secret key را در سایت یا مخزن عمومی قرار نده.

## اتصال در کد بازی

`multiplayer.js` آداپتور اولیه اتصال، ساخت/ذخیره شخصیت، پیوستن به اتاق، دریافت حرکت بازیکنان و چت را فراهم می‌کند. هنوز به حلقه اصلی بازی متصل نشده است؛ قبل از اتصال باید نقاط دقیق شروع بازی، جابه‌جایی صحنه و مختصات Canvas به اتاق‌ها و نقشه‌های مشترک نگاشت شوند.

## مراحل بعدی

1. اتصال امن و آزمایش ورود بازیکن.
2. ساخت صفحه انتخاب نام و شخصیت.
3. اتصال مختصات بازیکن به حضور زنده و رندر بازیکنان دیگر روی Canvas.
4. اتاق‌های جداگانه برای بخش‌های مختلف نقشه و انتقال بین آن‌ها.
5. چت، ذخیره پیشرفت، کنترل نرخ پیام و اعتبارسنجی سمت سرور.
6. تست چندبازیکنه و سپس انتشار نسخه آنلاین.

## محدودیت نسخه اول

این یک پایه اولیه برای نمونه چندنفره است، نه MMO آماده انتشار. برای جلوگیری از تقلب و دستکاری داده، بعداً منطق حساس بازی و اعتبارسنجی موقعیت/پاداش باید به سمت سرور منتقل شود.
