# MM World Preview

نسخه اولیه بازی نقش‌آفرینی آنلاین MM. امکانات: نقشه آزاد دوبعدی، دهکده و جنگل، حرکت لمسی/کیبورد، انتخاب نام و ظاهر، ورود ناشناس Supabase، نمایش زنده بازیکنان، چت جهانی و ماموریت جمع‌آوری گیاه.

برای چندنفره واقعی باید دو دستگاه/مرورگر را هم‌زمان وارد کرد و حرکت و چت دوطرفه را آزمایش کرد. سطح و تجربه در پروفایل آنلاین ذخیره می‌شوند؛ سکه و وضعیت ماموریت فعلاً محلی هستند. این نسخه نمونه اولیه است و هنوز MMORPG کامل یا ضدتقلب‌شده نیست.
