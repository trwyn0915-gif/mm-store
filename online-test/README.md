# MM World Preview

این پوشه شامل نمونه اولیه قابل توسعه بازی نقش‌آفرینی MM است.

## امکانات موجود
- دنیای دوبعدی آزاد با دهکده، ساختمان‌ها، جنگل و دریاچه
- حرکت کیبورد و کنترل لمسی موبایل
- انتخاب نام و ظاهر کاراکتر
- اتصال ناشناس Supabase و حضور زنده بازیکنان
- نمایش نام و موقعیت بازیکنان دیگر
- چت جهانی ذخیره‌شونده
- ماموریت ساده جمع‌آوری گیاه، سطح، تجربه و سکه
- ذخیره موقعیت و پیشرفت سطح/تجربه در پروفایل آنلاین
- پوسته نصب‌پذیر اولیه (manifest/service worker)

## اجرای آزمایشی
این پوشه باید از طریق HTTPS و پس از انتشار GitHub Pages اجرا شود؛ بازکردن مستقیم فایل با `file://` کار نمی‌کند.

## آزمایش پیشنهادی
1. دو مرورگر یا دو دستگاه را باز کنید.
2. با دو نام متفاوت وارد شوید.
3. حرکت هر بازیکن را در دستگاه دیگر بررسی کنید.
4. چت را از هر دو سمت امتحان کنید.
5. صفحه را تازه‌سازی کنید و ذخیره نام، موقعیت و سطح را بررسی کنید.

چندبازیکنه واقعی تا زمان انجام این آزمایش دو دستگاهی تأییدشده محسوب نمی‌شود.
